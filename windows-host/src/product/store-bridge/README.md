# Packaged Microsoft Store bridge

This .NET 8 Windows helper is the only process allowed to call
`Windows.Services.Store.StoreContext`. It is deliberately UI-free and accepts a
maximum of 32 newline-delimited JSON requests of at most 16 KiB each.

The packaged host must set `WORKSBIEN_LIFETIME_STORE_ID` to the **12-character
Store ID generated by Partner Center** for the non-expiring Durable add-on whose
product ID is `lifetime_unlock`. A request with any other Store ID is refused.

Supported actions are `readiness`, `getProduct`, `getLicense` and `purchase`.
Every request contains the configured `storeId`; `purchase` must also contain the
decimal HWND of the owning app window. The bridge calls
`WinRT.Interop.InitializeWithWindow.Initialize` before showing Store UI.

`getProduct` returns `StoreProduct.Price.FormattedPrice`; the JavaScript host
must display that string verbatim. `purchase` is only an initiation result. The
host grants Lifetime access only after a subsequent `getLicense` returns the
matching active Durable license.

Example request (the ID is illustrative and must never be shipped):

```json
{"action":"getProduct","storeId":"9ABCDEFGHIJK","hwnd":0}
```

Build on Windows or a CI runner with the .NET 8 SDK:

```powershell
dotnet build -c Release WorksBien.StoreBridge.csproj
```
